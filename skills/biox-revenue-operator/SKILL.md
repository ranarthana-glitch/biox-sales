# BioX Revenue Operator

Use this skill for daily, weekly, monthly, quarterly, and annual sales planning.

## North Star
Founder-set ambition: **$3 trillion in value creation / enterprise value by 2035**. Treat this as a strategic scale ambition, not a literal SaaS revenue forecast.

## Work backwards
2035 ambition → current strategic stage → next credible revenue milestone → annual target → quarterly target → monthly target → required qualified pipeline → current opportunities → funnel bottleneck → highest-value action today.

## Current milestone ladder
1. First qualified enterprise discovery
2. First enterprise pilot
3. First paid pilot
4. Repeatable pilot-to-contract motion
5. ₹10L cumulative contracted revenue
6. ₹1Cr ARR
7. ₹10Cr ARR
8. Recalculate subsequent targets from actual sales economics

Do not invent later-stage targets without observed pricing, win rate, sales-cycle length, retention, expansion, and delivery capacity.

## Core dashboard
Track:
- Revenue target

- Highest-value next action

## Definitions
A connection request is activity, not pipeline.
An accepted connection is activity, not pipeline.
A friendly reply is engagement, not pipeline.
A meeting becomes a qualified opportunity only when there is a credible buyer/problem/use-case, a commercial next step, and plausible deal value.

## Daily prioritization logic
If pipeline is thin: prospect and create qualified conversations.
If replies are weak: fix targeting/message before adding volume.
If conversations do not become meetings: fix CTA and qualification.
If meetings do not become pilots: fix discovery, demo relevance, pilot design, or stakeholder mapping.
If pilots do not close: address ROI, procurement, pricing, authority, legal, or implementation risk.
If warm opportunities exist: advance them before adding cold accounts.

## Governing question
**Given BioX's current revenue target, pipeline and funnel constraint, what is the single highest-value commercial action to take next?**

## Reporting style
Be numerically explicit. Flag missing data rather than inventing it. Be willing to say that more prospecting is the wrong action when the bottleneck is elsewhere.
